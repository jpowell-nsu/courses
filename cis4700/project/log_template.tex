\section{Session Log}

Entries accumulate toward your next submission, due at weeks 2, 7, 11, and 17. Spread entries across the period rather than writing one at the last minute, see the Submission Tracker near the end of this file for the full schedule.

\begin{tipBox}[Example entry (for reference)]
\textbf{Date:} Sept 18 \quad \textbf{Present:} Priya, Marcus \quad \textbf{Time spent:} about 2 hours \\
\textbf{What we worked on:} Getting the kernel to boot in QEMU. \\
\textbf{What changed:} Switched from a monolithic config to a minimal config with only the drivers we need. \\
\textbf{Decisions made, and why:} Chose a minimal config over the distro default because build times were too slow to iterate on. We can add drivers back later. \\
\textbf{Problems encountered:} Lost an hour to a missing initramfs step. \\
\textbf{Resources or tools consulted:} The kernel config documentation, and a forum thread that explained the missing initramfs step. \\
\textbf{Next steps:} Get networking working inside the VM.
\end{tipBox}
