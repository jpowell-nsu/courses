\section*{About This Guide}
This guide collects resources for the Hack The Box Certified Junior Cybersecurity Associate (CJCA) portion of the course. The CJCA is a hands-on, hybrid certification, so this list leans toward practice platforms, self-assessment tools, and community support alongside the required HTB Academy path. Each entry includes a one-line description and a link.

\section{Exam Snapshot}
CJCA is a 100 percent practical exam completed over a 5-day window, combining machine compromise with blue-team log and alert analysis. A candidate must complete 100 percent of the Junior Cybersecurity Analyst job-role path and hold a valid exam voucher before starting the exam. The table below summarizes the domains covered.

\begin{table}[htbp]
\centering
\caption{CJCA skill domains and focus areas}
\begin{tabular}{@{}p{0.32\linewidth}p{0.6\linewidth}@{}}
\toprule
\rowcolor{navy}
\textcolor{white}{\textbf{Domain}} & \textcolor{white}{\textbf{Focus Area}} \\
\midrule
IT and networking fundamentals & Linux, Windows, and core networking concepts \\
\rowcolor{lightrow} Network traffic analysis & Packet capture and analysis with Wireshark and tcpdump \\
Security monitoring and SIEM & Elastic Stack, KQL queries, and SOC fundamentals \\
\rowcolor{lightrow} Offensive security basics & Enumeration and basic exploitation with tools such as Nmap and Metasploit \\
Incident handling and threat hunting & The NIST SP 800-61 process and threat hunting with Elastic \\
\rowcolor{lightrow} Professional reporting & Documenting findings in a professional security report \\
\bottomrule
\end{tabular}
\end{table}

\section{Official HTB Resources}
\begin{itemize}

\item \textbf{\href{https://academy.hackthebox.com/app/paths/424/details}{Junior Cybersecurity Analyst Job-Role Path}} -- The required 20-module learning path that must be completed before the exam can be started.
\item \textbf{\href{https://academy.hackthebox.com/path/preview/junior-cybersecurity-analyst}{Junior Cybersecurity Analyst Path Preview}} -- A public preview of the path outline and module descriptions, viewable without an HTB Academy login.

\end{itemize}

\section{Hands-On Practice Beyond the Path}
\begin{itemize}
\item \textbf{\href{https://tryhackme.com/path/outline/presecurity}{TryHackMe Pre Security Path}} -- A free, beginner-friendly path covering networking, Linux, and Windows basics that pairs well with the early HTB modules.
\item \textbf{\href{https://help.hackthebox.com/en/articles/6007919-introduction-to-starting-point}{HTB Starting Point}} -- A guided track of very easy, beginner-friendly machines on the main HTB Labs platform, useful for building offensive-side confidence alongside the path.
\end{itemize}
